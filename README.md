# FAKHAMA DECOR — Digital Product Showroom

Immersive Editorial Showroom built with React + TypeScript + Vite.

## Development

### Quick Start

```
start_server.bat   → Start development server
stop_server.bat    → Stop development server
```

Double-click either file from Windows Explorer, or run from a terminal in the project root.

### Manual Commands

```bash
npm install        # Install dependencies
npm run dev        # Start Vite dev server
npm run build      # TypeScript check + production build
npm run preview    # Preview production build
```
